1. Write a query using CASE to categorize salary levels on Employees table: 
• <20000 → Low 
• 20000–50000 → Medium 
• 50000 → High

Ans :

SELECT 
    EmpId,
    EmpName,
    Salary,
    CASE 
        WHEN Salary < 20000 THEN 'LOW'
        WHEN Salary BETWEEN 20000 AND 50000 THEN 'MEDIUM'
        WHEN Salary > 50000 THEN 'HIGH'
    END AS PriceCategory
FROM Employees;

3. Create an encrypted and schemabound view that: 
• Joins Employees, Departments, and Salaries tables 
• Returns only employees who joined in the last 3 years 
• Includes computed column: AnnualSalary = Salary * 12 
• Prevents updates to base tables that break schema binding 
Tasks 
1. Create the view with WITH SCHEMABINDING, ENCRYPTION. 
2. Try altering an underlying table column → observe the error. 

Ans : 

REATE VIEW view_task
WITH SCHEMABINDING, ENCRYPTION
AS
SELECT 
    e.EmpId,
    e.EmpName,
    e.DeptId,
    d.DeptName,
    e.JoinDate,
    e.Salary,
    (e.Salary * 12) AS AnnualSalary
FROM dbo.Employees AS e
INNER JOIN dbo.Departments AS d 
    ON e.DeptId = d.DeptId
WHERE 
    e.JoinDate >= DATEADD(YEAR, -3, CONVERT(date, GETDATE()));

4. Create a view that: 
• Joins Employees + Sales 
• Shows total sales per employee 
• Shows rank based on total sales across company 

Ans :

CREATE VIEW view_task4 AS
SELECT 
    e.EmpId, 
    e.EmpName, 
    SUM(s.SaleAmount) AS TotalSales,
    DENSE_RANK() OVER (ORDER BY SUM(s.SaleAmount) DESC) AS SalesRank
FROM dbo.Employees e
LEFT JOIN dbo.Sales s
    ON e.EmpId = s.EmpId
GROUP BY 
    e.EmpId, e.EmpName;

7. Compare Rank / Dense_Rank / Row_Number 
• Identify top 2 per region 

Ans :

SELECT EmpName, Salary,
RANK() OVER(ORDER BY SALARY DESC) AS Salary_Rank,
DENSE_RANK() OVER(ORDER BY SALARY DESC) AS Dense_Salary_Rank,
ROW_NUMBER() OVER(ORDER BY SALARY DESC) AS Row_Salary_Rank
FROM Employees;

8. First CTE: Filter only last 1 year sales 
• Second CTE: Compute total sales per region 
• Third CTE: Rank regions based on total sales 
• Output top 3 regions

Ans :

with cte_last_year as 
(
    select 
        saleid,
        empid,
        region,
        saleamount,
        saledate
    from dbo.sales
    where saledate >= dateadd(year, -1, getdate())
),
cte_region_totals as
(
    select
        region,
        sum(saleamount) as totalsales
    from cte_last_year
    group by region
),
cte_region_rank as
(
    select
        region,
        totalsales,
        rank() over(order by totalsales desc) as salesrank
    from cte_region_totals
)
select *
from cte_region_rank
where salesrank <= 3;

9. Perform Pagination and list all details from employees who’s page between 6 and 10

Ans :

WITH EmployeePages AS
(
    SELECT EmpId,EmpName,
    ROW_NUMBER() OVER (ORDER BY EmpId) AS Page_Number
    FROM Employees
)
SELECT *
FROM EmployeePages
WHERE Page_Number BETWEEN 2 AND 4;
